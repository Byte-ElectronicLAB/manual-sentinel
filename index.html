1 Introducción y Descripción General

El Sentinel Pro es un sistema de protección y monitoreo inteligente para motores eléctricos. Protege compresores de heladeras, aires acondicionados y bombas contra las fallas más comunes que los destruyen prematuramente.

Medición RMS Real

No picos, no promedios. Valor cuadrático medio verdadero con 2000 muestras/150ms.

Corte Inteligente

SSR de estado sólido sin partes mecánicas. Corte en microsegundos ante fallas.

Conectividad Total

WiFi, OTA, Google Sheets, NTP y comunicación con el Termostato Dual.

¿Qué problemas soluciona?

Falla Causa Típica Acción del Sentinel
Motor clavado (Stall) Rotor trabado, cap. arranque abierto Corta SSR + alerta sonora + log nube
Ciclos cortos (Rateada) Protector térmico, bajo voltaje Cuenta 3 cortos seguidos -> bloqueo
Sobrecorriente Cortocircuito, cable dañado Alerta inmediata + registro en nube
Temperatura Crítica Falla en refrigeración del motor Interlock con Termostato Dual (Corte remoto)
Falla de gas / vacío Fuga de refrigerante, filtro tapado Detecta consumo anómalo y corta

2 Encendido y LCD

Al conectar el equipo, el Sentinel Pro realiza una rutina de diagnóstico:

  • Auto-Zero: Calibra el sensor ACS712 buscando el punto medio de 2.5V (RMS).
  • WiFi Connect: Intenta conectarse a la red configurada. Si falla, genera su propio Punto de Acceso.
  • LCD 16x2: Muestra el amperaje en tiempo real, el estado del motor y la IP asignada.
💡 Truco: Si el LCD muestra "Calibrando..." y hay una carga conectada, el valor Zero será incorrecto. Asegúrate de encenderlo sin carga.

3 Dashboard Web

El dashboard v6.1.3 es el corazón del monitoreo. Incluye:

  • Gráfico Real-Time: Muestra la curva de consumo actual.
  • Pico Máximo (Inrush): Captura el golpe de corriente inicial para diagnosticar capacitores débiles.
  • Duty Cycle: Porcentaje de tiempo que el motor ha estado encendido desde el boot.
  • Log de Eventos: Historial rápido de las últimas 8 acciones.
  • Control de Nodos: Puedes ver y controlar el Termostato Dual directamente desde aquí.

9 Especificaciones Técnicas

Sensores Utilizados

  • ACS712 (Hall Effect): Sensor de corriente lineal. Soporta hasta 30A (ventanas de 5A, 20A o 30A según modelo).
  • ESP32 (Core): Microcontrolador Dual Core que maneja la lógica de protección en un núcleo y la web en otro.
  • LCD I2C: Dirección estándar 0x27. Usado para monitoreo local sin necesidad de celular.
  • SSR 25A (Solid State Relay): Corte por cruce por cero para minimizar el arco eléctrico y el ruido.

10 Los Trucos del Sistema

Anti-Flicker

El sistema espera 3 confirmaciones (450ms) antes de decidir que el motor cambió de estado.

I2C Inmune

Reloj bajado a 50kHz para evitar que los ruidos del compresor congelen el LCD.

WDT Inteligente

Watchdog configurado a 15s para permitir reintentos TCP sin resetear el equipo.

⚠️ Nota sobre 24h Test: El modo test fuerza un log a la nube cada 24 horas aunque no haya cambios, para verificar que la conexión sigue viva.

11 Integración Cloud

Usamos Google Apps Script para registrar cada arranque y parada. Los datos enviados incluyen:

  • Amperaje de trabajo y Pico inicial.
  • Duración exacta del ciclo (segundos).
  • Motivo del Boot (Power-On, Brownout, WDT).
  • Temperaturas S1 y S2 del termostato vinculado en el momento del evento.
