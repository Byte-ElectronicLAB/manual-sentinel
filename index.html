INTEGRATED EDITION | v6.1.2

Manual de Operación de Grado Industrial

1. Descripción del Sistema

El Sentinel Pro v6.1.2 es un sistema de protección activa para motores y compresores. Utiliza un sensor de corriente ACS712 y un microcontrolador ESP32 para detectar anomalías antes de que ocurra un daño permanente.

⚠️ Importante: Esta versión está optimizada para trabajar en conjunto con el Termostato Dual v5.2 mediante comunicación WiFi local (Interlock de Seguridad).

2. Configuración de Parámetros

Parámetro Valor Sugerido Descripción
Zero ADC ~1862 Punto neutro del sensor ACS712. Se autocalibra al encender si no hay carga.
Stall Umbral 4.0 A - 6.0 A Límite máximo de corriente que el motor puede soportar antes de ser considerado "clavado".
Interlock Temp 55.0 °C Si el termostato remoto supera esta temperatura, Sentinel corta por seguridad.
Short Cycle 8 Seg Tiempo mínimo que debe durar un ciclo para no ser considerado "rateada" o corto.

3. Lógica de Protección (Cortes)

El dispositivo puede cortar la corriente (abrir el SSR) en los siguientes casos:

  • Protección Stall: El motor superó el umbral de corriente por más tiempo del permitido.
  • Ciclos Cortos: Se detectaron 3 intentos de arranque fallidos seguidos (rateo).
  • Falla de Gas: El consumo bajó drásticamente estando encendido (compresor girando en vacío).
Bloqueo de Seguridad: Si el sistema corta por Stall o Ciclo Corto, permanecerá bloqueado 5 minutos o hasta un **Rearme Manual** desde el panel web.

4. Panel de Diagnóstico

En el Dashboard podrás ver banners de colores con el estado de salud:

  • OK: Operación normal dentro de los rangos.
  • ADVERTENCIA: Ciclos largos o picos de corriente elevados.
  • ALERTA: El motor está clavado o bloqueado por seguridad.
