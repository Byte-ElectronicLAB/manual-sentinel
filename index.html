1. Introducción y Descripción General

El Sentinel Pro es un sistema de protección y monitoreo inteligente para motores eléctricos.

MEDICIÓN RMS REAL

No picos, no promedios. Valor cuadrático medio verdadero con 2000 muestras/150ms.

CORTE INTELIGENTE

SSR de estado sólido sin partes mecánicas. Corte en microsegundos ante fallas detectadas.

CONECTIVIDAD TOTAL

WiFi, OTA, Google Sheets, NTP y comunicación nativa con el Termostato Dual.

¿Qué problemas soluciona?

Falla Causa Típica Acción del Sentinel
Motor clavado (Stall) Rotor trabado, capacitor de arranque abierto Corta SSR + alerta sonora + log en la nube
Ciclos cortos (Rateada) Protector térmico actuando, bajo voltaje Cuenta 3 ciclos cortos seguidos -> Bloqueo
Falla de gas / Vacío Fuga de refrigerante, filtro tapado Detecta consumo anómalo (muy bajo) -> Corte
Sobrecorriente Cortocircuito, cable dañado Alerta inmediata + registro en nube
Temperatura crítica Sobrecalentamiento del sistema Interlock con Termostato Dual

3. Panel Web (Dashboard) Guía Completa

Accedé desde cualquier browser escribiendo la IP del Sentinel (visible en el LCD). El panel se actualiza automáticamente cada 1.2 segundos.

Colores del Panel de Diagnóstico

VERDE OK: Normal

Todo funciona correctamente. Se muestra duración promedio y amperaje promedio de los últimos 8 ciclos.

AMARILLO Recopilando / Advertencia

Acumulando datos (menos de 2 ciclos) o ciclos demasiado largos / consumo alto. Revisar gas o filtros.

ROJO ALERTA CRÍTICA

Motor clavado, múltiples stalls o 3+ ciclos cortos. El equipo ya cortó la corriente. Rearmar solo después de inspeccionar.

Truco: Botón REARMAR

Solo aparece cuando hay una protección activa. Al hacer clic, el Sentinel habilita el SSR y emite 2 pitidos de confirmación. El rearme automático ocurre a los 5 minutos si nadie lo rearma manualmente.

4. Sistema de Alertas y Sonidos del Buzzer

El Sentinel comunica su estado con un buzzer activo. Aprender el código de sonidos permite diagnosticar el sistema sin abrir ningún panel web.

2 Pitidos Cortos NORMAL

Arranque exitoso del motor O Rearme manual exitoso desde la web. Todo OK.

Pitido Largo EMERGENCIA

Motor clavado (stall), ciclos cortos o falla de gas. El SSR ya cortó la corriente. Inspeccionar.

3 Pitidos Desc. OFFLINE

WiFi desconectado. El Sentinel sigue protegiendo sin conexión. Se intentará reconectar.

2 Pitidos Medianos NODO

El Termostato Dual reportó una alerta activa de temperatura. Revisar interlock.

5. Botón Físico de Reset (Triple Confirmación)

El GPIO 13 acepta un pulsador externo (NA a GND) para resetear el contador de ciclos sin necesidad de la web. Un sistema de 3 pulsaciones evita borrados accidentales.

Timeout de Seguridad (3 Segundos)

Si dejás pasar más de 3 segundos entre pulsaciones, el proceso se cancela automáticamente y vuelve al monitoreo normal. No se borra nada.

  1. Primera pulsación (Inicio del proceso)
    LCD muestra: Borrar contador? / [BOTON] 2 mas ... (Suena 1 pitido corto)
  2. Segunda pulsación (Confirmación primaria)
    LCD muestra: Seguro en serio? / [BOTON] 1 mas ... (Suena 1 pitido corto)
  3. Tercera pulsación (Ejecución)
    Contador en 0. Suenan 2 pitidos de confirmación y el LCD vuelve al Dashboard normal.

Elegir el sensor correcto es crítico

Un sensor de 5A con un motor de 10A destruirá el sensor. Usar siempre un margen del 130-150% sobre la corriente nominal del motor.

Filtro RC ¿Por qué es indispensable?

El ACS712 genera ruido de alta frecuencia (HF) en su salida analógica. Sin un filtro (Resistencia 1kΩ en serie y Capacitor 100nF a GND), el ADC del ESP32 lee valores erróneos que disparan arranques fantasma.

10. Lógica Interna y Los Trucos del Sistema

10.1 Cálculo RMS Real (Root Mean Square)

A diferencia de un simple voltímetro, el Sentinel toma 2000 muestras en 150ms. Eso significa 5 ciclos completos de 50Hz para máxima precisión en corriente alterna.

// Pseudocódigo del cálculo RMS
for(i = 0; i < 2000; i++) {
    raw = analogRead(PIN_SENSOR);    // 0-4095 del ADC 12bit
    delta = raw - cfg.zero;          // Sustrae el punto de cero (sin carga)
    sumSq += delta * delta;          // Acumula cuadrados
}
rms = sqrt(sumSq / 2000);            // Raíz cuadrática media
amperios = rms * cfg.sensibilidad;   // Convierte a Amperios

10.8 WDT Perro Guardián de Hardware (15 segundos)

Si el procesador se traba en cualquier operación de red o flash por más de 15 segundos, el hardware reinicia el equipo automáticamente (esp_task_wdt_reset()).

10.9 Curva de Consumo en Tiempo Real — Google Sheets NUEVO v6.4.7

Esta feature permite visualizar el comportamiento exacto del amperaje durante todo el ciclo, no solo el valor máximo. Sirve para diagnosticar si una subida de consumo fue progresiva (desgaste o calentamiento) o abrupta (trabamiento o cortocircuito).

📈 ¿Cómo funciona?

El Sentinel almacena 1 muestra de amperaje por minuto en RAM (hasta 120 muestras = 2 horas). Al terminar el ciclo, compacta esos datos como una cadena CSV (ej: 1.50,1.62,1.78,2.11,3.05) y la envía en el mismo request a Google Sheets.

Configuración en Google Sheets (SPARKLINE)

Una vez que el script de Google Apps Script recibe el parámetro curve, debés escribir en la columna de tu planilla la siguiente fórmula para generar el gráfico automáticamente en la celda:

=SPARKLINE(
  SPLIT(I2, ","),
  {"charttype","line"; "color","#3b82f6"; "linewidth",2}
)

⚠️ Importante

Reemplazá I2 por la celda que contiene la cadena CSV enviada por el Sentinel (la columna donde el Apps Script guarda el parámetro curve). El SPLIT(..., ",") convierte el texto en números para el gráfico.

12. Ecosistema Byte-ELECTRONICLAB (Termostato Dual)

El Sentinel Pro v6.4.x se integra de forma nativa con el Termostato Dual DS18B20, formando un sistema de protección integral para el ciclo frigorífico completo.

Interlock por Temperatura Crítica (Seguridad Cruzada)

Si el Termostato Dual reporta una temperatura superior a maxTempSafety (configurable, default 55°C), el Sentinel corta el SSR del compresor aunque el amperaje sea completamente normal. Esto protege el condensador o evaporador de un sobrecalentamiento destructivo.

14. Glosario Técnico

RMS: Root Mean Square (valor eficaz real de una corriente alterna)
Inrush: Corriente de arranque, típicamente 6-8x la corriente nominal
Stall: Motor trabado mecánicamente (alto consumo sin movimiento)
SSR: Solid State Relay (relé sin partes mecánicas, corte por triac)
WDT: Watchdog Timer (reinicio de emergencia por hardware)
Interlock: Bloqueo cruzado de seguridad (un sistema protege al otro)
