Parte I: Manual de Uso Diario (Para el Propietario)

Dominando tu Sentinel Pro

1. Primer Contacto: ¿Qué veo en mi aparato?

El Sentinel Pro tiene una pantalla de cristal líquido que te informa el estado de tu equipo las 24 horas. Aquí no hay códigos raros, solo información útil:

Mensaje Significado Real Ejemplo
0.0 A El motor está apagado y descansando. La heladera llegó a la temperatura deseada.
1.5 A (Variable) El motor está encendido y enfriando. Consumo normal de un motor de 1/4 HP.
TOTAL: 24 Cuántas veces arrancó en el día. Si este número sube muy rápido, revisa los burletes.
💡 Ejemplo Práctico de Ahorro

Si notas que tu Sentinel marca TOTAL: 80 en un solo día, tu heladera está arrancando demasiado seguido. Esto suele ser porque la puerta no cierra bien o le falta gas. El Sentinel te está avisando que estás gastando luz de más.

2. Las Alarmas: ¿Qué hacer si suena?

Tu Sentinel es un guardaespaldas. Si suena, es porque salvó al motor de morir.

🔔
PITIDO LARGO = ACCIÓN REQUERIDA

El equipo cortó la luz para que el motor no se prenda fuego.

Pasos para Rearmar:

  1. Entra al panel web desde tu teléfono.
  2. Verás un botón ROJO gigante que dice "REARMAR".
  3. Presiónalo. El motor intentará arrancar de nuevo.
  4. IMPORTANTE: Si el motor intenta arrancar y el Sentinel lo vuelve a cortar a los 2 segundos, NO lo rearmes más. Llama a un técnico porque el motor está trabado eléctricamente.
Parte II: Manual Técnico de Ingeniería (Para el Instalador)

Arquitectura y Algoritmos

1. Procesamiento DSP y True RMS

El Sentinel Pro no estima el consumo; lo procesa digitalmente. El sensor Hall ACS712 envía una señal analógica que el ESP32 digitaliza a alta velocidad.

PROCESAMIENTO DE 2000 MUESTRAS POR CICLO

¿Por qué es importante? Los motores generan ruidos y armónicos. Un protector común fallaría por lecturas falsas. El Sentinel integra la curva de corriente para obtener el valor RMS real.

2. Protección de Ciclos Cortos (Short Cycle)

Este algoritmo previene que el motor intente arrancar repetidamente contra una presión de gas alta (lo cual quemaría el bobinado de arranque).

⚙️ Lógica de Bloqueo

Si Tiempo_Marcha < 8 segundos, el sistema marca un "Evento de Ciclo Corto". Al llegar a 3 eventos seguidos, el SSR se abre permanentemente y requiere rearmado manual.

3. Health Score Engine (Salud Térmica)

Esta es la función más avanzada de la v6.2.7. Analiza la inercia térmica del sistema.

CRÍTICO NORMAL ÓPTIMO (85%)

El sistema mide el tiempo de descanso promedio. Si detecta que los descansos se acortan más de un 40% sin que suba la temperatura ambiente, asume que hay una falla en la aislación o burletes.

3. Configuración y Parámetros

El panel de configuración permite tunear el equipo para cualquier motor (desde una heladera familiar hasta un chiller industrial).

Parámetro Uso Técnico Valor Recomendado
Zero Amps Calibración del sensor sin carga. 2048 - 2500 (Auto)
Trigger Amps Amperaje máximo antes de disparar alarma. 1.5x Amperaje Nominal
Min Watts (minwa) Detecta motor girando en vacío (fuga de gas). 0.3A para heladeras

4. Resolución de Problemas (FAQ)

P: La pantalla muestra letras chinas o símbolos raros.

R: Es interferencia eléctrica (EMI). El Sentinel tiene un sistema de Self-Healing que repara la pantalla automáticamente cada 2 minutos. No afecta la protección.

P: El WiFi no conecta.

R: Si el router está muy lejos, el equipo activa el Modo AP (Punto de Acceso). Conéctate a la red "Sentinel_Pro" para configurar el WiFi de nuevo.

P: ¿Cómo actualizo el firmware?

R: Descarga primero tu backup desde la pestaña OTA. Luego sube el nuevo .bin. Si algo falla, puedes volver al backup en segundos.
